# Contributing

This repository is a curriculum and project-learning workspace.

## Learning workflow

Students will work through individually assigned practice tasks and contribute to the shared build through pull requests.

The final workflow will follow these principles:

1. Work is attributable to the learner who completed it.
2. Tasks have stable IDs.
3. Tasks map to specific files.
4. Work is reviewed through pull requests.
5. Learning evidence matters as much as the final code.
6. Students are expected to explain **why**, not only **what**.

## Important

The exact task, branch, commit, review, and merge rules will be defined in the student workflow documents before Sprint 1 starts.
