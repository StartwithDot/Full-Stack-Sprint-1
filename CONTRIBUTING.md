# Contributing

This repository is both a learning environment and a shared project workspace.

## Core rules

1. Work should remain attributable to the learner who completed it.
2. Tasks will use stable IDs and explicit file paths.
3. Individual practice belongs under `students/`.
4. Shared product work belongs under `platform/`.
5. Shared deliverables belong under `delivery/`.
6. Work should be reviewed through pull requests once the student workflow is published.
7. Explanations should include **why** a choice was made, not only what was done.
8. Do not commit secrets, passwords, local environment files, or generated dependency directories.

The detailed branch, commit, pull-request, and review workflow will be finalized with the Full Stack student guide.
