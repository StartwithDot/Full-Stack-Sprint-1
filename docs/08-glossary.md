# Glossary

This is the beginning of the Sprint 1 glossary.

| Term | Working meaning |
|---|---|
| browser | software that requests and displays web content |
| client | the part of a system making a request |
| server | software that receives requests and performs application work |
| request | a message asking a server to do or return something |
| response | the server's answer to a request |
| route | a server rule for handling a particular request |
| API | a defined way for software to communicate |
| JSON | a common text format for structured data |
| DOM | the browser's in-memory representation of the HTML document |
| event | something that happens in the browser, such as a click |
| database | persistent structured storage for application data |
| SQL | a language for working with relational databases |
| CRUD | create, read, update and delete |
| asynchronous | work whose result may arrive later rather than immediately |
| validation | checking whether input is acceptable |
| authentication | establishing who a user is |
| authorization | deciding what an identified user is allowed to do |

Definitions will be expanded as new concepts are introduced.
