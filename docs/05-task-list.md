# Sprint 1 Task List

**Status: Working draft**

The final task list will be derived from the curriculum blueprint after the learning sequence is approved.

Every final task should contain:

- stable task ID
- learner outcome
- concrete instructions
- exact file path
- expected evidence
- teaching note explaining the trap, proof, or later connection
- checkpoint or review requirement where appropriate

The task list should preserve the Data Sprint traceability principle:

**task → file → commit → review → learner**

The final list must also separate beginner foundation tasks from tasks that assume earlier programming knowledge.
