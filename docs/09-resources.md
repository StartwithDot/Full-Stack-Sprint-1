# Learning Resources

The final resource list will be selected to match each unit and learner level.

Resources should be mapped to tasks rather than given as a large unstructured reading list.

## Resource principles

Prefer material that:

- explains the mental model before syntax
- is beginner-accessible
- can be connected immediately to the current task
- does not require a different stack unless the comparison teaches something useful

Each unit should identify:

**LEARN → DO → PROVE**

rather than simply listing links.
