# Student Guide

## How the learning workspace works

Each student has a personal workspace under `students/FS<n>/`.

Each time-box has its own folder.

Use the unit file in `docs/_week-templates/` as the shared curriculum definition, and your personal `problem_statement.md` as your task workspace.

## Expected working rhythm

1. Read the whole unit before starting.
2. Read the learning material connected to the task.
3. Complete the individual practice.
4. Commit small, understandable changes.
5. Open a pull request when the task requires review.
6. Review at least one teammate's work when assigned.
7. End the unit by explaining what changed and why.

## Important

The final task ID, branch naming, PR rules, and merge policy will be published after the Full Stack curriculum sequence is agreed.
