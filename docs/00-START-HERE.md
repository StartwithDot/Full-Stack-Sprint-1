## Start with the mental model

Before focusing on frameworks, understand the basic path:

```
User
  ↓
Browser
  ↓
HTML + CSS + JavaScript
  ↓
Request
  ↓
Server
  ↓
Database
  ↓
Response
  ↓
Browser updates
```

The Poll Maker is the concrete system through which this model becomes understandable.
