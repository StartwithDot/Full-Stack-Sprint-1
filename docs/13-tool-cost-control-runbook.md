# Tool Cost Control Runbook

The curriculum should not require students to pay for optional services just to complete Sprint 1.

## Principles

- prefer local tools where they are sufficient
- identify free-tier requirements before publishing a unit
- never hide a required paid dependency inside a resource link
- distinguish required tools from optional productivity tools
- provide a low-cost or no-cost path whenever practical

## Sprint 1

The initial Poll Maker direction is intentionally based on common local development tools so the core learning does not depend on a paid platform.
