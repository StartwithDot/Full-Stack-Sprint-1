# Cohort Learning Design

Sprint 1 is designed for mixed-background learners.

## The problem

A single pace can be too slow for experienced learners and too fast for beginners.

## Teaching response

The curriculum should keep the shared project and milestones common while allowing practice depth to vary.

A beginner may need:

- more guided practice
- vocabulary support
- smaller checkpoints
- explicit debugging steps

A learner with prior experience may need:

- explain-why tasks
- alternate implementations
- edge-case analysis
- comparison tasks

## Shared rule

Different levels should not mean different core outcomes.

Everyone should be able to explain the same essential application flow by the end.
