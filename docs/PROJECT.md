# Sprint 1 Project — Poll Maker

**Status: Working draft**

## Project idea

A simple web application where users can view one poll, choose an option, submit a vote, and see updated results.

The application is intentionally limited so that learners can understand the entire flow rather than assembling a large feature set.

## Current technical direction

The current project brief proposes:

- Frontend: HTML, CSS, vanilla JavaScript
- Backend: Node.js + Express
- Database: MySQL with raw SQL

These technologies are provisional curriculum choices and will be retained only where they support the learning sequence.

## Deliberate constraints

Sprint 1 should not introduce advanced features simply because they are common in modern production stacks.

Features such as authentication, multiple polls, true real-time updates, TypeScript, ORMs, testing frameworks and frontend frameworks can become later learning steps.

## Success principle

The most important success criterion is not the number of features.

A successful learner can explain what happens from a user action in the browser through the application layers and back again.
