# Unit Templates

These files are the shared time-box templates.

Each unit should eventually contain:

- Before you start
- By the end of this unit you can
- At a glance
- ordered task groups
- teaching notes
- milestone/checkpoint where relevant
- end-of-unit checklist
- short-on-time cut line
- Next unit link

The templates are initially scaffolded for Full Stack Sprint 1 and remain editable while the curriculum is being designed.
