# Tools and Technology

This document explains why each tool is used, not only how to install it.

## Current Sprint 1 direction

| Tool | Why it is here |
|---|---|
| HTML | structure the page |
| CSS | make the interface readable and expressive |
| JavaScript | add behaviour in the browser |
| Node.js | run JavaScript outside the browser |
| Express | make server routes easier to build and understand |
| MySQL | persist application data |
| SQL | communicate with the database |
| Git | record work over time |
| GitHub | collaborate, review and share the project |

## Explicitly deferred

React, TypeScript, ORMs, authentication, WebSockets and other advanced tooling are deferred where they would obscure foundational learning.

The reason for every later technology should be connected to a problem students first experience.
