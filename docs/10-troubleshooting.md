# Troubleshooting

This guide will grow from actual cohort problems.

## First response to an error

Before asking for help, capture:

1. what you expected
2. what actually happened
3. the exact error message
4. what you changed immediately before it happened
5. what you already tried

## Browser problems

Check:

- browser console
- Network panel
- page source/DOM where appropriate

## Server problems

Check:

- terminal output
- route path
- HTTP method
- request body
- server process status

## Database problems

Check:

- connection details
- database/table name
- SQL syntax
- whether the expected row exists

The final guide will contain concrete known traps from the Poll Maker build.
