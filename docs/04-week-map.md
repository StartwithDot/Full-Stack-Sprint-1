# Sprint 1 Map

**Working scaffold: 13 time-boxes, following the structural shape of Data Sprint 1.**

The exact pacing can still change after the teaching sequence is reviewed.

| Unit | Working theme |
|---|---|
| 1 | Understand the web and the product |
| 2 | HTML structure and page semantics |
| 3 | CSS basics and readable UI |
| 4 | JavaScript fundamentals and data in memory |
| 5 | DOM, events and browser behaviour |
| 6 | First working frontend checkpoint |
| 7 | Node.js and the server mental model |
| 8 | HTTP, routes and Express |
| 9 | Databases, SQL and persistence |
| 10 | Connect browser, server and database |
| 11 | CRUD and product behaviour |
| 12 | Async behaviour, validation, errors and refinement |
| 13 | Handover, demo and rebuild-from-understanding checkpoint |

This map is a curriculum scaffold, not yet the final lesson plan.
