# Tools Setup

This guide will be expanded before the first cohort starts.

## Expected tools

Sprint 1 currently expects:

- a modern web browser
- a code editor
- Node.js and npm
- Git
- a GitHub account
- MySQL

## Setup principle

Install only what the current learning stage needs.

A tool is not part of the curriculum simply because it is common in industry.

## Verification

The final setup guide will include simple checks such as:

```bash
node --version
npm --version
git --version
```

and a local MySQL connection check.

Students should be able to explain what each installed tool is for before moving on.
