# Platform and CI/CD Guide

## Why a shared platform exists

The shared platform is the group's assembled product.

It should show how individual practice becomes one working application.

## Current planned shape

```
platform/
├── frontend/
├── backend/
└── database/
```

The exact source layout may change as the curriculum design is completed.

## CI/CD

Automation should be introduced only when it teaches a useful engineering idea.

The first priority is not sophisticated deployment. It is a clear, repeatable way to verify that the shared project is in a runnable state.

No final CI workflow is committed yet.
