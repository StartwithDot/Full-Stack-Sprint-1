# Project Brief — Poll Maker

## 1. The client ask

The client wants a small web application that lets people answer one question and see the current voting results.

The exact product scope is intentionally small so learners can understand the whole system.

## 2. Core requirement

The application must allow a user to:

- view one poll and its options
- vote for an option
- see updated vote counts
- add an option
- remove an option

## 3. Deliberate boundaries

Sprint 1 does not need:

- accounts and authentication
- multiple independent polls
- true real-time push updates
- React or another frontend framework
- TypeScript
- an ORM
- a testing framework

These omissions create useful questions for later sprints.

## 4. Definition of success

The learner should be able to demonstrate the product and explain one complete action from browser to server to database and back.

## 5. Product constraint

Do not make the application large enough to hide the learning.

A smaller system that the learner understands is more useful than a larger system assembled by imitation.
