# Student Workspaces

Each learner has an individual workspace.

Current scaffold:

```
students/
├── FS1/
│   ├── week1/
│   └── ...
└── FS30/
    └── week13/
```

The 30-workspace count mirrors the existing Data Sprint cohort structure. It can be adjusted when the actual Full Stack cohort size is known.

Each week contains a `problem_statement.md` that will carry the learner-facing task statement and evidence requirements for that unit.
